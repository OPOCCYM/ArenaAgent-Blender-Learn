# ArenaAgent-Blender-Learn

Реалистичный параметрический седан в Blender 4.2 (по мотивам Volvo S90). Весь проект полностью процедурный: сетки, UV-развёртки, материалы, освещение, камеры, анимация и экспорт в Unreal Engine генерируются Python-скриптами без внешних 3D-ассетов и растровых текстур.

## Состав репозитория

| Файл | Назначение |
|------|------------|
| `car_geometry.py` | чистые математические кривые, габариты, спецификация дверей и `sanitize_name` (без зависимости от `bpy`) |
| `car_build.py` | главный генератор сцены: кузов, остекление, колёса, салон, двери, фары/фонари, материалы, свет, камеры, анимация, сохранение `.blend` |
| `qa.py` | техническая проверка геометрии (дубли вершин, вырожденные грани, неманифолдные рёбра, n-gon, висячие элементы, UV и имена коллекции `Car`) |
| `render_stills.py` | перерендер 5 финальных кадров камер в `renders/` |
| `turntable.py` | облёт камерой на 360° (240 уникальных кадров) → `renders/turntable.mp4` |
| `export_ue.py` | экспорт коллекции `Car` в FBX для Unreal Engine 4/5 (масштаб 100, триангуляция, `UCX_*` коллизии, сохранение осей вращения в анимации) |
| `ue_preview_export.py` | оркестратор: предварительные рендеры 5 кадров + экспорт FBX за один запуск |
| `silhouette.py` | проверка силуэта по эталонным файлам из `ref/` (заглушка, ждёт файлы обмеров) |
| `tests/` | модульные тесты (`test_car_geometry.py`) и интеграционные тесты Blender 4.2 (`test_blender_pipeline.py`) |

## Требования

* Blender 4.2 LTS (проверено на 4.2.23 LTS, в том числе через Python-модуль `bpy==4.2.*`).
* Все текстуры процедурные (PIL не требуется).
* Для сборки MP4 в `turntable.py` опционально используется `ffmpeg`.

## Сборка и запуск

```bash
# 1. Собрать сцену и сохранить car_realistic.blend
blender -b -noaudio -P car_build.py

# Собрать сцену и сразу отрендерить 5 финальных кадров (можно указать --samples и --out-dir)
blender -b -noaudio -P car_build.py -- --render --samples 48

# 2. Проверить геометрию (все счётчики ошибок должны быть нулевыми)
blender -b -noaudio car_realistic.blend -P qa.py

# 3. Перерендерить 5 статичных кадров
blender -b -noaudio car_realistic.blend -P render_stills.py

# 4. Облёт 360° (240 кадров, 12 fps -> 20 с; --pingpong добавляет обратный ход)
blender -b -noaudio car_realistic.blend -P turntable.py
```

## Система координат и габариты

* `+X` — перед (нос `+2.50 м`, передняя ось `AXLE_F = +1.60 м`)
* `-X` — корма (`-2.50 м`, задняя ось `AXLE_R = -1.46 м`)
* `+Y` — левый борт (сторона водителя), `-Y` — правый борт
* `+Z` — вверх, дорога `Z = 0.0 м`

| Параметр | Значение |
|----------|----------|
| Длина × ширина × высота | 5.00 × 1.872 × 1.432 м (низкий фастбэк-силуэт Volvo S90) |
| Колёсная база | 3.06 м (`AXLE_F = +1.60`, `AXLE_R = -1.46`) |
| Колея | 1.584 м (`WHEEL_Y = 0.792`) |
| Шина | 235/45 R18, радиус 0.353 м, ширина 0.235 м |
| Минимальный дорожный просвет (`ZB`) | 0.16 м |
| Радиус арки / глубина впадины | 0.445 м / 0.13 м |
| Купол носа / кормы | 0.14 / 0.14 м (суперэллипс `pe=0.34`, `px=0.72`) |
| Сечений вдоль X | 200 |
| Точек профиля кузова / остекления | 18 / 9 |

Сцена разделена на две коллекции (всего 102 объекта, 0 дефектов QA):
* `Car` — вся геометрия автомобиля (`Body` со сквозным вырезом салона/дверных проёмов, моторным отсеком и нишей багажника, отдельная крыша `Roof`, 6 несущих стоек `Pillar_A/B/C_L/R`, лобовое, заднее и боковые треугольные форточки `Glass`, тороидальные шины `Wheel_*`, 10-спицевые диски `Rim_*`, тормозные диски `Brake_Disc_*` и суппорты `Brake_Caliper_*`, скульптурные кромки арок `Wheel_Arch_*` и подкрылки `Wheel_Well_*`, профилированные двери `Door_*` по единой кривой борта `side_surface_y` с оконными рамками, стёклами `Door_Glass_*`, ручками `Door_Handle_*`, петлями `Door_Hinge_*` и каплевидными зеркалами `Mirror_L/R`, отделённый капот `Hood_Lid` + `Engine_Bay` + петли/лифты `Hood_*`, отделённый багажник `Trunk_Lid` + `Trunk_Floor` + петли/лифты `Trunk_*`, фирменная вогнутая решётка Volvo `Grille_Front` + `Grille_Chrome` с 15 ламелями и эмблемой Iron Mark, контурный воздухозаборник `Bumper_Intake_Front`, огибающие фары «Молот Тора» `Headlight_*`/`Headlight_DRL_*`/`Headlight_Lens_*`, C-образные задние фонари `Tail_Light_*`, контурный задний диффузор `Rear_Diffuser` и двойные хромированные патрубки `Exhaust_L/R`, интерьер `Cabin`/`Dashboard`/`SteeringWheel` и др.).
* `Studio` — освещение, 8 камер (`Cam_Exterior`, `Cam_Rear`, `Cam_Side`, `Cam_Interior`, `Cam_Interior2`, `Cam_Trunk`, `Cam_Door_Cutout`, `Cam_Hood`) и студийный пол `Cyclorama` (исключается из экспорта в Unreal Engine).

## Материалы (процедурные, совместимы с Blender 4.2)

| Материал | Описание |
|----------|----------|
| `CarPaint_MetallicBlue` | `(0.055, 0.115, 0.280)`, Metallic 0.62, Roughness 0.26, Coat 1.0/0.03 + микрорельеф |
| `Glass_Window` | `Transparent + Glossy` через `Layer Weight` (без `Transmission`), тонировка 0.58, Roughness 0.065 |
| `Lens_Clear` | `Transparent + Glossy` по `Fresnel` (IOR 1.52) — линзы фар и экран |
| `Rubber_Tire` | Протектор по цилиндрической UV (`uv_cyl`): `Checker + Wave` с маской боковины и `Bump` |
| `Leather_Seat` / `Carpet` / `Headliner_Fabric` | Зерно по бокс-UV (`uv_box`) + мягкая вариация шероховатости через `MapRange` |
| `Headlight_Light` / `DRL_Light` / `Tail_Light` | Приглушённая эмиссия `0.55 / 0.22 / 0.16` |

## Свет, камеры, рендер и анимация

* Интерьер: 5 Area-ламп (`Int_RoofLight_F`, `Int_RoofLight_M`, `Int_SeatLight`, `Int_DashLight`, `Int_Ceiling`), направленных в салон.
* Студия: 6 Area-ламп вокруг машины (нацелены на `TARGET = (0.05, 0, 0.74)`), студийный пол `Cyclorama` под `Z = 0` и опциональный HDRI `hdri/studio_small_09.hdr`.
* Камеры: `Cam_Exterior`, `Cam_Rear`, `Cam_Side`, `Cam_Interior`, `Cam_Interior2`.
* Рендер: Cycles CPU, 48 spp, `AgX` (`AgX - Medium High Contrast`), 1440×810, `transparent_max_bounces = 48`, `blur_glossy = 2.0`.
* Анимация (240 кадров / 24 fps):
  * `Wheel_FL/FR/RL/RR` (и привязанные к ним `Rim_*`) — 40 оборотов вокруг локальной оси Y;
  * `SteeringWheel` — ±17° вокруг локальной оси X;
  * `Body` — крен ±0.8° вокруг X;
  * `Door_Front_Left/Right`, `Door_Rear_Left/Right` — открывание **наружу** на 70° (кадры 45–200) вокруг шарнира у передней кромки каждой двери;
  * `Trunk_Lid` — отделённая крышка багажника открывается вверх на 62° (кадры 45–200) на петлях «гусиная шея» (`Trunk_Hinge_Arm_L/R`), а газовые упоры (`Trunk_Lift_Cyl_L/R` + `Trunk_Lift_Rod_L/R`) телескопически выдвигаются по `TRACK_TO`.

## Экспорт в Unreal Engine (FBX)

```bash
# Предварительные рендеры + экспорт FBX за один запуск
blender -b -noaudio car_realistic.blend -P ue_preview_export.py

# Или отдельно только экспорт FBX
blender -b -noaudio car_realistic.blend -P export_ue.py
```

Файлы в `exports/`:

| Файл | Содержимое | Использование в UE |
|------|-----------|-------------------|
| `car_ue.fbx` | статичные меши коллекции `Car` + встроенные коллизии `UCX_<Имя>` | основной статичный ассет (UE автоматически связывает `UCX_*` внутри одного FBX) |
| `car_ue_anim.fbx` | меши коллекции `Car` с анимацией (колёса, руль, крен, двери) и сохранёнными осями/шарнирами | анимированный вариант / Skeletal или Animated Static preview |
| `car_ue_col.fbx` | только коллизионные коробки `UCX_*` | отдельный просмотр/проверка коллизий |

Параметры экспорта: масштаб `100.0` (м → см), оси `Forward = -X`, `Up = Z`, триангуляция (`use_triangles=True`), сглаживание по граням (`mesh_smooth_type='FACE'`), гарантированный UV-канал и санитизированные имена без пробелов и точек.
