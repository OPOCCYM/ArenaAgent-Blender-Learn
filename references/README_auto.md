# Реалистичный автомобиль в Blender — готовый проект + разбор

В workspace лежит **работающий проект**: параметрический седан, который собирается кодом
(`car_build.py`), сохраняется в `.blend` и рендерится в Cycles.

```
car_build.py            ← генератор: кузов, колёса, интерьер, материалы, риг, анимация, студия
car_realistic.blend     ← готовая сцена (HDRI упакован внутрь, ни от чего не зависит)
hdri/studio_small_09.hdr← студийное HDRI (Poly Haven, CC0)
render_exterior.png     ← 3/4 спереди
render_side.png         ← профиль
render_rear.png         ← 3/4 сзади
render_interior.png     ← салон, вид с заднего ряда
render_interior2.png    ← салон, вид от пассажира
turntable.mp4           ← анимация: облёт + вращение колёс и руля
turntable.py            ← скрипт этой анимации (рендер покадрово)
rerender3.py            ← перерендер кадров экстерьера без пересборки сцены
silhouette.py           ← сверка силуэта с эталоном (маска + таблица расхождений)
ref/                    ← обмеры с реальной модели + эталонный контур (см. 2.1)
```

Анимация: `blender -b car_realistic.blend -P turntable.py` (рендерит кадры в `frames/`),
затем `ffmpeg -framerate 24 -i frames/tt_%04d.png -vf scale=1280:720 turntable.mp4`.

Размер сцены ~5 МБ (HDRI запакован внутрь), 300+ объектов, рендер кадра
1440×810 на 48 сэмплах Cycles CPU — около 3 минут на 2 ядрах.

---

## 1. Как запустить

**Вариант А — просто открыть.** `car_realistic.blend` открывается в Blender 4.2 LTS (и в 4.0–4.5).
Внутри уже всё: материалы, свет, камеры, анимация. Жмите F12.

**Вариант Б — пересобрать с нуля / поменять параметры:**

```bash
blender -b -P car_build.py              # собрать и сохранить .blend
blender -b -P car_build.py -- --render  # собрать и отрендерить 5 кадров
```

или внутри Blender: `Scripting → Open → car_build.py → Run Script`.

> Файл `hdri/studio_small_09.hdr` должен лежать рядом со скриптом. Если его нет —
> сцена автоматически перейдёт на процедурное окружение (менее красиво, но работает).

## 2. Что внутри сцены

Коллекции: `CAR → 01_Body, 02_Wheels, 03_Interior, 04_Details, 05_Rig` + `ENV_Studio`.

### Кузов — единая оболочка, а не набор кубиков

Кузов строится как **лофт по 174 поперечным сечениям**. Каждое сечение — гладкая
кривая (Catmull-Rom) из 22 точек «тела» + 10 точек «остекления»: низ, порог,
борт, плечо, подоконная линия, окно с наклоном внутрь, скат и центр крыши.

Положение этих точек задаётся шестью «кривыми-профилями» вдоль машины:

| Кривая | Что задаёт |
|---|---|
| `W(x)` | полуширину кузова (макс. 0.936 м = 1.87 м) |
| `ZB(x)` | низ (порог, бамперы) |
| `BELT(x)` | подоконную линию — низ стёкол (сзади уходит на крышку багажника) |
| `ZR(x)` | крышу и «коронку» капота/багажника |
| `WR(x)` | полуширину крыши |
| `TUMBLE(x)` | наклон бокового стекла внутрь (tumblehome) |

> **Важно:** все кривые сняты не «на глаз», а с реальной машины (см. раздел 2.1).
> `ZR(x)` — это буквально контур кузова с ортогонального вида сбоку, оцифрованный
> по пикселям и переведённый в метры.

Хотите другой силуэт — меняете 5–20 чисел, а не 8000 вершин. Например, чтобы
сделать купе: сдвиньте `ZR` влево (короче крыша) и поднимите `ZT` сзади.

**Колёсные арки вырезаны прямо в сечении**: функция `z_opening(x)` возвращает
кромку проёма над осью колеса (полуэллипс 0.445 м по длине, вершина 0.765 м —
как у штампованного крыла), и все точки борта ниже этой линии поднимаются до неё.
Поэтому арка настоящая, а не «накладка поверх колеса».

**Нос и корма скругляются** отдельной поправкой сечения (`TIP_F` / `TIP_R`):
точки стягиваются к центру и к середине по высоте, поэтому торец — не плоская
стенка, а обтекаемая поверхность, на которой нормально лежат фара и решётка.

**Остекление** — не отдельные плоскости, а участки той же оболочки. Материал
назначается граням по их реальной высоте и координате X (`build_body`):
получаются лобовое, боковые стёкла, заднее, стойки-рамки (чёрный трим), причём
переход между стеклом и кузовом — идеальный шов без зазоров.

Дальше: `Subdivision Surface` (1 уровень во вьюпорте, 2 на рендере) + гладкий
шейдинг. Все фаски скругляются сабдивом, поэтому блики «текут» без изломов.

### Детали (04_Details)

Детали передка и кормы **сажаются на поверхность кузова через raycast**
(`body_hit` / `face_patch`): луч извне пробивает реальную (с сабдивом) оболочку и
возвращает точку + нормаль, поэтому фара, решётка, номер и фонарь лежат на
скруглённом носу ровно, без «коробок в воздухе» и без утопания внутрь.

Фары (патч по поверхности кузова + тёмный корпус + две линзы-проектора + DRL-«бровь»),
задние фонари со световой полосой, решётка с хром-ламелями, нижний воздухозаборник,
сплиттер, диффузор с плавниками, двойной выхлоп, зеркала (с прорезанным **Boolean**
окном в кузове — как у настоящих машин), ручки, молдинги, хром по линии остекления,
пороги, канты арок, подкрылки, номерные знаки, щётки, антенна-плавник, лючок бака,
зазоры панелей (тонкие тёмные ленты, лежащие на поверхности).

### Колёса (02_Wheels)
Шина 235/45 R18 (R = 0.353 м) — тело вращения с профилем (буртик, плечо,
протектор) и канавками, сгруппированными по 4 подряд сегмента (шаг 10 → 12
шашечек по кругу). Диск 18" — 5 сдвоенных спиц, ступица, колпачок, 5 болтов,
тормозной диск, суппорт.
Левая сторона — gunmetal, правая — светлый алюминий.

### Интерьер (03_Interior)
Торпедо с козырьком приборки и тремя колодцами, центральный экран, дефлекторы с
ламелями, **руль** (обод-торус, три спицы, ступица, эмблема, вал), сиденья с
боковыми валиками, подголовниками и декоративной строчкой, задний диван с
подлокотником, тоннель с селектором КПП и подстаканниками, карты дверей с
подлокотниками/ручками/динамиками, обивка потолка, пол, педали, салонное зеркало.

### Материалы
Всё на процедурных нодах, без текстур-файлов:

* **CarPaint_MetallicBlue** — металлик 0.62, шероховатость 0.26, отдельный слой
  лака (`Coat Weight = 1`, `Coat Roughness = 0.03`) + микро-бамп «хлопьев»
  (`Noise` 2400 + `Bump`). Цвет меняется в одном поле `Base Color`:
  `(0.055, 0.115, 0.280)` — синий металлик; для красного `(0.30, 0.02, 0.02)`,
  для белого перламутра `(0.62, 0.63, 0.65)` + `Metallic 0.15`.
* **Glass_Window** — `Transparent` + `Glossy` через `Mix Shader` с
  `Layer Weight (Fresnel)`: под прямым углом стекло прозрачное, под скользящим —
  отражает. Плюс лёгкая тонировка (0.58). Именно такая схема (а не
  `Transmission`) держит салон освещённым: Cycles не считает каустику внутри
  машины, и с настоящим преломлением интерьер выходит чёрным.
* **Headliner_Fabric** — светлая ткань потолка (0.085): без неё салон
  «схлопывается» в чёрное пятно.
* **Leather_Black / Leather_Accent** — зерно из `Noise` + `Voronoi` → `Bump`,
  разброс тона через `ColorRamp`.
* **Rubber** — почти чёрный, шероховатость 0.78, микро-бамп.
* Хром, gunmetal, алюминий, сталь, карбон, красный суппорт, светящиеся DRL/фары/фонари,
  экран приборки (emission), номерной знак, стекло зеркал.

### Студия
HDRI `studio_small_09` (Poly Haven) + 5 мягких area-лампочек + 4 маленькие лампы
внутри салона (не видны камере, `visible_camera = False`), бесконечный пол,
5 камер: 3/4 спереди, профиль, 3/4 сзади, две в салоне. Рендер: Cycles CPU,
AgX + Medium High Contrast, denoise.

## 3. Анимация

Всё уже проставлено на 240 кадров (24 fps = 10 секунд). В `turntable.mp4` —
облёт камеры на 360° (241 кадр, туда-обратно = 20 с) при работающих колёсах и руле.

| Что | Объект | Как сделано |
|---|---|---|
| Вращение колёс | `Wheel_FrontL/R`, `Wheel_RearL/R` | `rotation_euler[1]` (локальная Y) 0 → 40 оборотов, интерполяция **LINEAR** |
| Поворот передних колёс | пустышки `Steer_L`, `Steer_R` | `rotation_euler[2]` (мировая Z) ±16–17°, Bezier |
| Руль | `SteeringWheel_Rig` | вращение вокруг локальной Z, передаточное отношение **11:1** |
| Крен кузова | `Body_Rig` | `rotation_euler[0]` ±0.8° + микро-подъём по Z |

Колёса крутятся вокруг **своей** оси, потому что они — дети поворотных кулаков:
поворот кулака не наклоняет ось вращения колеса.

**Чтобы машина реально ехала** — в `build_animation()` раскомментируйте:

```python
for f, x in ((F0, 0.0), (F1, 14.0)):
    key(root, "location", f, x, 'LINEAR', index=0)
```

(14 м за 240 кадров ≈ 50 км/ч). Хотите «быстрее» — увеличьте `turns` (число
оборотов) и дальность синхронно: `turns = distance / (2πR)`, R = 0.353 м.

Хотите замедлить вращение для крупного плана — уменьшите `turns`, но помните:
если машина «едет», число оборотов должно соответствовать пути, иначе колесо
будет «буксовать» — это первое, что выдаёт нереалистичную анимацию.

## 4. Если делаете свою машину с нуля — рабочий порядок

1. **Референсы.** Три проекции (спереди/сбоку/сверху) в Image Editor, выставить
   масштаб по колёсной базе (у нас **3.06 м**), не по длине кузова. Готовые
   чертежи с размерами есть на drawingdatabase.com / dimensions.com.
2. **Блок-аут.** Кузов — не куб с сабдивом, а лофт по сечениям (как здесь):
   8–12 сечений достаточно, чтобы поймать силуэт, дальше сгущайте.
3. **Главные линии.** Порог, плечо, подоконная линия, скат крыши. Кузов
   «читается» именно ими — блики потом сами сделают объём.
4. **Арки и колёса — первыми.** Колесо задаёт всё: арку, посадку, высоту.
   Колесо должно быть видно целиком и не «утопать» в кузове.
5. **Сабдив + фаски.** `Subdivision` 2 на рендере, всем мелким деталям —
   `Bevel` 2–4 сегмента. Без фасок ни один край не даёт правдоподобный блик.
6. **Стекло отдельным материалом на гранях** (как здесь) — так не бывает щелей
   между стеклом и кузовом, которые сразу выдают 3D.
7. **Зазоры панелей.** Тонкие тёмные ленты по дверям/капоту/багажнику: 5 мм
   ширины — и машина перестаёт быть «мыльной».
8. **Свет решает больше, чем материалы.** HDRI + 2–3 мягких источника. Плоский
   свет = пластик, даже с идеальным металликом.
9. **Материал краски**: тонкий слой лака (`Coat`) + низкая шероховатость.
   Не делайте «зеркало» (roughness 0) — получится пластиковая игрушка.
10. **Камера**: фокусное 50–70 мм для экстерьера (не ширик — он растягивает
    пропорции), высота 1.4–1.7 м, диафрагма f/5.6–f/8.

## 5. Быстрые правки под себя

| Хочу | Где менять |
|---|---|
| Другой цвет кузова | `mat_paint()` → `Base Color` |
| Более «глянцевый» лак | `Coat Roughness` 0.025 → 0.01 |
| Матовый кузов | `Coat Weight` → 0, `Roughness` → 0.45 |
| Другой профиль шины / диска | `tire_geo()` — список профиля; `spoke_geo()` — спицы |
| Другая посадка (ниже/выше) | `WHEEL_R`, `Z_ARCH`, `ZB(x)` |
| Длиннее/короче база | `AXLE_F`, `AXLE_R` (и не забыть `ARCH_R`) |
| Другой наклон стёкол | `TUMBLE(x)` — 0.06 (вертикально) … 0.16 (сильный наклон) |
| Другой силуэт крыши | `ZR(x)` — можно просто взять контур с чертежа |
| Фары/решётка «плывут» | `body_hit`/`face_patch` сами сажают их на поверхность; правьте только диапазоны y/z |
| Другой салон (бежевый) | `mat_leather("Leather_Black", (0.030, 0.029, 0.031))` — цвет |
| Открыть двери | прорезать дверь Boolean по контуру из `PanelGap`, затем `Rotation` вокруг петли |
| Другой HDRI | положить файл в `hdri/` и поменять имя в `build_scene()` |
| Больше/меньше сэмплов | `sc.cycles.samples` (48 — норм для CPU, 128 — для финала) |
| Разрешение | `sc.render.resolution_x/y` |
| EEVEE вместо Cycles | `sc.render.engine = 'BLENDER_EEVEE_NEXT'` — в 4.2 работает, но металлик и стекло будут проще |

## 6. Что честно стоит знать про этот проект

* Кузов — процедурный, но **обмеры и силуэт сняты с реального седана** (см. 2.1):
  колёсная база 3.06 м, колея 1.63 м, ширина 1.87 м, высота 1.456 м, профиль
  крыши совпадает с эталоном в пределах ~5 мм на ключевых точках. Это не скан и
  не копия конкретной модели: детали (фары, решётка, фонари) — авторские,
  «по мотивам», а не воспроизведение чужого дизайна.
* Двери не открываются (нет петель и прорезанных контуров) — это следующий шаг,
  если нужна анимация «двери открываются, садится человек».
* Колёса — отдельные объекты, не привязаны к симуляции: для езды по неровностям
  нужен `Follow Path` / `Rigid Body` + подвеска.
* Внутри салона геометрия упрощённая (без ремней, швов, кнопок на руле) — на
  общих планах читается, на макро не хватит.
* Заднее стекло и крышка багажника сходятся в «быстрый» лифтбек-профиль: у
  реального седана там ещё есть отдельная полка багажника.
* Пол капота/порожков внутри пустой: если снимать с прозрачными стёклами и
  сильным контровым светом, видно, что «под капотом» ничего нет.
* Скрипт писался под Blender 4.2. В 3.6 не заработает (другие имена входов
  Principled BSDF: `Coat Weight` / `Transmission Weight`).
